# GLB Reader — Design Spec
Date: 2026-06-21

## Purpose

A CLI tool that reads a GLB file and prints a human-readable, token-efficient tree of its node hierarchy. Intended to be passed to an LLM for analysis or comparison between different GLB files generated by this project.

## Location

`src/core/glb_reader.py`

Single file. Contains a `read_glb(path: str)` function (importable) and a `__main__` block for CLI use.

## Usage

```bash
python src/core/glb_reader.py schematic.glb
python src/core/glb_reader.py 2d.glb
```

## Output Format

A single header line followed by the indented node tree printed to stdout.

```
schematic.glb  [nodes:42, meshes:18, scenes:1]

Package [children:5, mesh:no]
  DesignatorName [children:0, mesh:yes]
  PackageValue [children:0, mesh:yes]
  FirstPinMarker [children:2, mesh:no]
    silk_firstPinMarker [children:0, mesh:yes]
    fab_firstPinMarker [children:0, mesh:yes]
  Legs [children:8, mesh:no]
    1 [children:3, mesh:no]
      CopperCirclePad [children:0, mesh:yes]
      SolderMask [children:0, mesh:yes]
      text [children:0, mesh:yes]
  Body [children:3, mesh:no]
    fab_layer [children:4, mesh:no]
      BodyLine [children:0, mesh:yes]
```

### Node fields

| Field | Description |
|---|---|
| name | Node name from GLB, or `[unnamed]` if absent |
| children | Number of direct children |
| mesh | `yes` if node has geometry attached, `no` otherwise |

Indentation: 2 spaces per depth level.

## Implementation

### Dependencies

`pygltflib` — already listed in `pyproject.toml` optional deps under `[glb]`.

### Algorithm

1. Load file with `GLTF2().load(path)`
2. Print header: filename, total node count, total mesh count, scene count
3. Find root nodes via `gltf.scenes[0].nodes`
4. Walk the tree recursively:
   - Indent by `depth * 2` spaces
   - Print `{name} [children:{n}, mesh:{yes|no}]`
5. After walking all scenes, collect any node indices not visited. If any exist, print an `[orphaned nodes]` section listing them.

### Edge cases

- **Multiple scenes**: walk each scene in order, separated by a blank line with the scene index.
- **Orphaned nodes**: nodes not reachable from any scene root are listed at the end under `[orphaned nodes]`.
- **Unnamed nodes**: printed as `[unnamed]`.
- **Missing scene**: if `gltf.scenes` is empty, print all nodes flat with a warning.

## Out of scope

- Bounding boxes / geometry dimensions
- Material or texture details
- Buffer/accessor inspection
- Diff functionality (comparison is done externally via diff tools or by the LLM)
